# Autoparts Search

Клиентское приложение на React + Redux для подбора автозапчастей и аналогов через API сервиса «Проценка» (favorit-parts.ru).

## Требования

- Node.js 18 или новее (проверено на 18.20.8)
- npm 9 или новее
- Ключ покупателя (`key`), выданный сервисом

## Установка

1. Установите зависимости:

   ```bash
   npm install
   ```

2. Создайте файл с настройками на основе примера:

   ```bash
   copy .env.example .env.local
   ```

   (в Linux/macOS: `cp .env.example .env.local`)

3. Откройте `.env.local` и укажите свой ключ:

   ```env
   VITE_API_KEY=ваш-ключ-покупателя
   VITE_API_TARGET=http://api.favorit-parts.ru
   ```

   - `VITE_API_KEY` — обязательная переменная. Без неё приложение покажет ошибку при первом запросе.
   - `VITE_API_TARGET` — необязательная. Адрес сервиса, по умолчанию `http://api.favorit-parts.ru`.

   > Файл `.env.local` добавлен в `.gitignore` и не должен попадать в репозиторий.

## Запуск

### Режим разработки

```bash
npm run dev
```

После запуска откройте адрес, который выведет Vite (обычно `http://localhost:5173`).

### Продакшен-сборка

```bash
npm run build
```

Готовые файлы появятся в папке `dist/`.

Просмотр собранной версии локально:

```bash
npm run preview
```

## Важно про CORS и прокси

В режиме разработки (`npm run dev` и `npm run preview`) запросы к API идут через прокси Vite: браузер обращается к `/api/hsprice`, а Vite перенаправляет их на `VITE_API_TARGET`. Это обходит ограничения CORS.

При развёртывании `dist/` на веб-сервере прокси Vite не работает. Нужно настроить прокси на сервере, например nginx:

```nginx
location /api/hsprice {
    proxy_pass http://api.favorit-parts.ru/hs/hsprice;
    proxy_set_header Host api.favorit-parts.ru;
}
```

## Типичные проблемы

| Симптом | Причина и решение |
|---|---|
| «Не задан ключ API» | Не создан `.env.local` или не указан `VITE_API_KEY`. После изменения `.env.local` перезапустите `npm run dev`. |
| «Invalid key client!» | Ключ неверный или не активирован у сервиса. Проверьте значение ключа. |
| «Request quota exceeded!» | Исчерпан лимит запросов по грузовому ассортименту. Обратитесь к поставщику. |
| «Сервис недоступен» | Нет сети или сервис не отвечает. Проверьте подключение и доступность `VITE_API_TARGET`. |
| «Превышено время ожидания» | Сервис отвечает дольше 15 секунд. Повторите запрос позже. |
| Запросы не проходят в собранной версии | Прокси Vite не работает в `dist/`. Настройте прокси на веб-сервере (см. раздел выше). |
